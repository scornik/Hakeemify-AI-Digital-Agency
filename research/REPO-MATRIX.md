## Highest novelty (>= 7)

- **onlook-dev/onlook** (7/5, Adapt): A write-time 'source map for JSX' (stable data-oid stamped into source, indexed to file/line/column/enclosing-component/dynamic-context) that lets non-destructive DOM edits be replayed as inverse-safe serializable actions which are compiled into AST edits of the originating source.
- **chakra-ui/ark** (7/4, Adapt): One declarative state machine plus one pure connect() projection per widget serves every framework, including vanilla DOM, so accessibility semantics and keyboard behaviour are written once as data and the framework adapter is only an interpreter plus prop normaliser.
- **theatre-js/theatre** (7/4, Adapt): Animation as versioned, sanitised JSON state (definitionVersion + revisionHistory + per-prop deserializeAndSanitize) authored in a GUI and replayed by a runtime that layers defaults, static overrides and keyframe tracks addressed by object key + encoded prop path.
- **langchain-ai/langgraph** (7/3, Adapt): Treating agent execution as Pregel-style supersteps over reducer-typed channels, so that a checkpoint written after every step makes pause, resume, human interrupts, fan-out and forking into properties of the runtime rather than features bolted onto a loop.
- **browserbase/stagehand** (7/4, Adapt): observe() turns a natural-language intent into a concrete, replayable Action (selector + method + args) so the LLM run happens once and subsequent runs are deterministic locator calls, with a DOM-shape-keyed cache and self-heal fallback around that boundary.
- **GoogleChrome/lighthouse** (7/4, Adopt): A fully declarative audit plugin model (artifact -> audit -> normalized score + typed details -> weighted category) where the config is data, so any check can be added, removed or re-weighted without touching the runtime.
- **vercel-labs/json-render** (7/3, Adapt): One catalogue definition compiles to prompt + strict JSON Schema + validator simultaneously, so the thing the model is told, the thing the API enforces, and the thing the runtime checks can never drift apart.
